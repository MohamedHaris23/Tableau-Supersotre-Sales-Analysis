# Superstore Sales Analysis(Tableau)

## Project Overview
* Interactive Tableau dashboard analyzing  and evaluate retail performance, regional profitability and monthly sales for superstore sales.

## Tools & Technologies
* Application: Tableau
* Techniques used: Data Modelling, regional mapping, Data aggregation and filters.

## Key Business Insights
* Reginal distribution-- Analyze state-wise sales and profits margin using map layers.
* Trends-- Tracking monthly sales and growth over time.
* Top products-- Analyzing top selling products lines using dynamic and filtering.

## Files Included
* 'Superstore-Sales-Dashboard.twbx': The packaged Tableau workbook containing the complete data model, sheets and interactive dashboards..
